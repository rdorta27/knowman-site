## Database engine

$ knowman search "capital of mongolia"
No evidence found for that query.

Cada resultado es un pasaje con su rango de líneas. Con un modelo de lenguaje configurado, knowman ask redacta prosa a partir de esos mismos pasajes. La recuperación no necesita modelo de lenguaje. Fuente: core/README.md.

Qué hay dentro

Recuperación con citas

Los trozos conservan su rango de líneas, así que una cita apunta a las líneas exactas. Si nada cae dentro del umbral de distancia, es un negativo explícito.

Se mantiene al día

Un vigilante convierte las notas añadidas, editadas y borradas en trabajos, y un trabajador las indexa.

Cuatro formas de entrar

Una CLI, una API HTTP, un servidor MCP con search y ask, y un panel de monitoreo.

Local primero

Postgres con pgvector y Ollama para los embeddings. No hace falta clave de API; se puede configurar Claude, OpenAI o Grok para las respuestas.

Mira cada parte y el archivo que la implementa en la página de arquitectura.

Instalar

git clone https://github.com/rdorta27/knowman
cd knowman
./install.sh
docker compose exec api knowman search "why Postgres"

Necesita Docker y el plugin de Compose. En Arch, ./install.sh --mode native corre sin Docker. El script imprime los comandos de lo que falta y se detiene en vez de instalarlo.
