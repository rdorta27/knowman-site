The idea in three parts

Core concept

knowman is a program that reads a folder of Markdown notes. It answers your question with passages from those notes. Each passage shows its file and line range.

Physical analogy

Picture a librarian who serves one shelf only. You ask a question. The librarian hands you the matching pages, with the book and the line number. If no page matches, the librarian says so and hands you nothing.

Technical mechanics

  • Watcher detects each added, edited or deleted .md file and creates a job.
  • Worker claims one job at a time and runs it.
  • Chunker splits each note at blank lines and records the line range.
  • Ollama converts each chunk into a vector.
  • Postgres with pgvector stores the chunks and the vectors.
  • Search converts your question into a vector and returns the nearest chunks.
  • Distance filter drops chunks farther than 0.5. If none remain, it prints No evidence found for that query.

What it looks like

## Database engine

$ knowman search "capital of mongolia"
No evidence found for that query.

Each result is a passage with its line range. With a language model configured, knowman ask writes prose from those same passages. Retrieval needs no language model. The program prints its messages in English in every site language. Source: core/README.md.

What is inside

Cited retrieval

Chunks keep their line ranges, so a citation points at the exact lines. Nothing within the distance threshold means an explicit negative.

Live index

A watcher turns added, edited and deleted notes into jobs, and a worker indexes them.

Four entry points

A CLI, an HTTP API, an MCP server with search and ask, and a monitoring panel.

Runs locally

Postgres with pgvector and Ollama for embeddings. No API key is needed; Claude, OpenAI or Grok can be set for answers.

See each part and the file behind it on the architecture page.

Install

git clone https://github.com/rdorta27/knowman
cd knowman
./install.sh
docker compose exec api knowman search "why Postgres"

Needs Docker and the Compose plugin. On Arch, ./install.sh --mode native runs without Docker. The script prints the commands for anything missing and stops instead of installing it.
