O knowman indexa uma pasta de arquivos .md e responde só com essa pasta. Quando não encontra nada, ele diz isso em vez de inventar.

## Database engine

$ knowman search "capital of mongolia"
No evidence found for that query.

Cada resultado é um trecho com o seu intervalo de linhas. Com um modelo de linguagem configurado, knowman ask escreve prosa a partir desses mesmos trechos. A recuperação não precisa de modelo de linguagem. Fonte: core/README.md.

O que tem dentro

Recuperação com citações

Os trechos mantêm o intervalo de linhas, então uma citação aponta para as linhas exatas. Se nada estiver dentro do limite de distância, é o negativo explícito.

Acompanha as mudanças

Um vigia transforma notas adicionadas, editadas e apagadas em trabalhos, e um trabalhador as indexa.

Quatro formas de entrar

Uma CLI, uma API HTTP, um servidor MCP com search e ask, e um painel de monitoramento.

Local primeiro

Postgres com pgvector e Ollama para os embeddings. Nenhuma chave de API é necessária; Claude, OpenAI ou Grok podem ser configurados para as respostas.

Veja cada parte e o arquivo por trás dela na página de arquitetura.

Instalar

git clone https://github.com/rdorta27/knowman
cd knowman
./install.sh
docker compose exec api knowman search "why Postgres"

Precisa de Docker e do plugin do Compose. No Arch, ./install.sh --mode native roda sem Docker. O script imprime os comandos do que falta e para em vez de instalá-lo.
